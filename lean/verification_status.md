# P2588: статус Lean-проверки

Состояние: **PARTIAL / COMPILED**.

Lean 4.19.0, x86_64-unknown-linux-gnu, commit 6caaee842e94, Release.
Mathlib v4.19.0, commit c44e0c8ee63ca166450922a373c7409c5d26b00b.

## Выполнено

1. Скомпилирован модуль точной целочисленной арифметики и операций с многочленами.
2. Скомпилирован весь сертификат H, E, R, S6, включая коэффициенты 12 и 13,
   оба знаменателя, разности с половиной, сокращённую дробь и все предыдущие
   строгие сравнения для m<13.
3. Отдельно скомпилирована автономная объединённая версия без mathlib.
4. Скомпилированы конечная модель клауз, сохранение выполнимости при взятии
   подмножества, точный знаменатель, монотонность и условная теорема о пороге.
5. Выведены зависимости теорем: у арифметических результатов нет аксиом;
   у модельных теорем только propext, Classical.choice, Quot.sound.
6. Стандартная сборка всего проекта `lake build` фактически завершилась
   с кодом возврата 0; её вывод сохранён в `build.log`.

## Что не проверено ядром

Не доказаны равенства между `satCount` настоящих формул и коэффициентами S6.
Итоговая теорема явно условная. Без этих условий безусловный порог для
исходного случайного 2-SAT внутри Lean не получен.

Число 2381437338960 доказано как результат биномиального преобразования
конкретного целочисленного многочлена. Называть это полностью формализованным
подсчётом выполнимых 13-клаузных формул было бы неверно.

## Особенности окружения

Официальный бинарный дистрибутив Lean скачан без изменения кода ядра.
В контейнере числовой PID процесса не совпадает с числовыми каталогами /proc,
из-за чего стандартный поиск пути приложения через /proc/<pid>/exe не работал.
Для фактического запуска использован узкий адаптер: только запрос символьной
ссылки исполняемого файла текущего процесса переводится на /proc/self/exe.
Он не меняет Lean-выражения, тактики, редукцию, проверку доказательств или
код ядра, не предоставляет дополнительных прав. Исходник адаптера включён
как `environment/lean_namespace_compat.c` для прозрачности.

Распаковка дистрибутивов выполнялась без переноса владельцев из архивов.
Mathlib-модули получены штатным механизмом cache. Проектовые модули скомпилированы
бинарным Lean с этими импортами; журналы сохранены. В обычной системе такой
адаптер не нужен, достаточно команд из README.

Предыдущие исследовательский архив и PDF оставлены без изменения. Этот пакет
содержит отдельный формальный аудит и не повышает статус исходной задачи до
полного доказательства ядром.
